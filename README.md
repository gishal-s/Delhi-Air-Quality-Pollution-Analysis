# Delhi Air Quality & Pollution Analysis

## 📌 Project Overview

This project analyzes Delhi's 2025 hourly air-quality and weather data using Microsoft Excel and Power Query.

The objective is to identify air-quality patterns across different locations, months, hours, weather conditions and major pollutants.

## 📊 Dataset

- Year: 2025
- Observations: 52,560
- Monitoring locations: 6
- Original columns: 16
- Data frequency: Hourly

## 🛠️ Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Dashboard

## 🔍 Key Insights

- Moderate AQI accounted for 64.05% of observations.
- Severe AQI accounted for 15.36%.
- May had the highest monthly average AQI at 582.76.
- September had the lowest monthly average AQI at 123.89.
- Hourly AQI showed a peak around 18:00.
- 31.72% of observations were classified as High Pollution using the project's AQI > 200 rule.
